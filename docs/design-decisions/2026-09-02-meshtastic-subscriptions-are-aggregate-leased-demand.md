# Meshtastic subscriptions are aggregate leased demand

1. **Time and date:** 2026-09-02, America/New_York
2. **Name:** Link subscriptions request one shared Gateway feed rather than per-Asset delivery
3. **Context:** Assets need to request Core-backed data feeds over a shared low-bandwidth channel. Several Assets may want the same feed, and an Asset may shut down without sending an unsubscribe. Treating each subscription as a separate delivery would waste airtime, while permanent Gateway configuration would leave abandoned feeds transmitting indefinitely.
4. **Decision:** A Link subscription is a renewable request for the Gateway to broadcast and refresh selected Atlas data. The Gateway combines identical selectors across all joined Runtimes into one publication demand. The first subscriber causes the current value to be broadcast once, followed by later updates. Additional subscribers reuse that feed. One Runtime unsubscribing removes only its demand, and publication ends after the final demand is removed or expires. Each Runtime renews every thirty seconds and its Gateway lease expires after ninety seconds without renewal. Supported selectors are an exact Atlas record ID, all records of one supported type, and Tasks assigned to one Asset. The Gateway coalesces queued superseded state to the latest value.
5. **Alternatives considered:** Per-subscriber transmissions were rejected because they multiply airtime without changing channel visibility. Permanent subscriptions were rejected because feeds could survive after their consumers disappeared. Waiting for a future change before sending the first value was rejected because a quiet record could leave the requester without an answer. Preserving every intermediate update was rejected because obsolete positions and Track states compete with current information.
6. **Consequences:** The Gateway must maintain per-Runtime leases and aggregate them by a canonical selector. One or two lost renewals do not stop a feed, while demand from a vanished Runtime disappears within roughly ninety seconds. Every Runtime may ingest a published feed whether or not it subscribed. The same field-originated data may still cross the channel once from its Asset and again through a subscribed Gateway feed; that duplicate-path concern remains unresolved and must be measurable through provenance.
