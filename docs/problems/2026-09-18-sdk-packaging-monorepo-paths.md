1. **Time & Date:** 2026-09-18T15:00:56Z
2. **Name:** SDK packaging leaks the monorepo layout into published/tarball paths
3. **Issue:** Built SDK ships `dist/packages/protocol/` alongside its own output and consumers resolve entry points under `dist/packages/sdk/src/`, so repo-relative paths appear in stack traces, source maps, and the packed tarball.
4. **Severity:** S5
5. **Location:** packages/sdk/tsconfig.json:9,14; packages/sdk/package.json:27-31,60
6. **Expected:** The SDK package root maps to dist: entry point `./dist/index.js` (`dist/index.d.ts`), and the tarball contains only SDK output — the generated protocol module either included via a TypeScript project reference laid out under dist/, or copied into `src/` at prebuild so compilation stays inside the package.
7. **Actual:** tsconfig.json sets `rootDir: "../.."` to compile `../protocol/generated/typescript/index.ts` inside the package, so `tsc` mirrors the repo tree into `dist/` (`dist/packages/sdk/...`, `dist/packages/protocol/...`); `files: ["dist/"]` packs both, and every export/`bin` operand points at `./dist/packages/sdk/src/...`.
8. **Reproduction:** `cd packages/sdk && npm pack --dry-run` — tarball listing includes `dist/packages/protocol/generated/typescript/index.js` (126.7 kB) and entry `dist/packages/sdk/src/index.js` (55 files total). The built tree at packages/sdk/dist/packages mirrors this.
9. **Notes:** Severity reflects exposure: the SDK has no `private` flag and `publishConfig.access: "public"` (packages/sdk/package.json:62), but no release workflow publishes it (`.github/workflows/` only builds/tests the SDK in ci.yml:173-224), so it is currently workspace-only; consumers still resolve through the package name and the exports map, so they get `dist/packages/...` paths in module resolution and stack traces today, and `npm pack`/the packed-consumer smoke test would publish the leaked layout if a release ever runs. Fix options: (a) TypeScript project references so the generated module compiles into the SDK's own dist layout, or (b) a prebuild step copying the generated TS into `packages/sdk/src/generated/` so `rootDir` can be `src` — both yield `dist/index.js` and a clean tarball.
